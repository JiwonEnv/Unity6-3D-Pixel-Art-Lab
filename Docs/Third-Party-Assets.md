## Project adaptations

- The playable player is KayKit's **Knight**. Kenney Oopi was used during initial controller integration and remains available as a sample asset.
- Original FBX geometry, rigs and animations are imported through Unity's ModelImporter.
- Instances receive project-generated materials using the existing `PixelArtLab/Sprite Toon` shader.
- Kenney Nature material colors are adjusted to the scene palette; Castle, character and Platformer atlas textures are retained with Point filtering.
- Colliders, object IDs, Animator controller, movement, camera, game rules and map layout are project code.
- The continuous terrain and dirt trail meshes are generated by this project. They are not presented as downloaded assets.
- Original source files are preserved; converted materials are in `Assets/Art/OpenWorld`.

No ProPixelizer, paid character controller, paid environment asset or extracted Never's End content is included.
