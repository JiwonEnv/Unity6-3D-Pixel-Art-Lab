# 세미리얼 에셋 비교 씬

`Assets/Scenes/Semi-Real-Pixel-Woodland.unity`를 열고 Play.
기존 Amberwood 씬을 복제해 야영지와 호숫가 일부에 상세 환경을 적용했다.
캐릭터·야영 장비와 나머지 지역은 비교를 위해 기존 에셋을 유지한다.

## 기존 렌더링에 추가한 것

- 기존 Sprite Toon 셰이더에 노멀 맵, AO·거칠기, 직접광 GGX 반사와 연속 명암 혼합을 추가했다. 기본값은 0이므로 기존 재질은 기존 명암을 쓴다.
- 잎은 양면 조명과 투명 마스크를 사용한다. 색상 렌더링·그림자·물체 ID·깊이 패스 모두 같은 투명 경계와 바람 변형을 적용한다.
- 나뭇잎 텍스처의 투명 경계 색 번짐을 보정해 검은 테두리를 줄인다. 상세 에셋은 내부 선화를 약하게 한다. 노멀 맵의 미세 요철을 선화로 그리지 않는다.
- 물은 기존 수면 셰이더에 연속 시간의 겹친 파형, 두 방향으로 흐르는 잔물결 노멀과 평면 반사를 추가했다. 반사는 640×360, 최대 20회/초이며 수면·강수는 반사 카메라에서 제외한다.
- 낮·밤, 횃불, 바람, 비와 눈의 젖음·적설을 새 재질에도 적용한다.
- 비가 오면 맵 전역의 완만한 지면·흙길에 불규칙한 물웅덩이가 커진다. 캐릭터·나무·텐트를 실제로 뒤집어 렌더링한 별도 평면 반사와 빗방울 동심원으로 표현한다. Toon에서도 반사는 유지된다.
- 2로 비를 켜고 몇 초 기다리면 생성된다. 1로 맑게 바꾸면 남은 물기가 서서히 마른다. 눈이 쌓이면 웅덩이를 숨긴다. C로 호수와 웅덩이의 반사를 함께 비교한다.

초기 버전의 높이 1.1m 제한은 제거했다. 이 제한이 같은 높이의 등고선을 따라 띠 모양으로 물웅덩이를 만들던 원인이었다. 현재는 맵 전체의 완만한 지면에 6m 셀별로 중심·크기·모양을 달리 배치한다. 급경사와 호수 아래 지면은 제외하며, 같은 맵에서는 위치가 유지된다. `PuddleMask.cginc`와 `PuddleSurface.cs`가 같은 정수 해시와 마스크 수식을 사용해 보이는 물과 발 판정을 맞춘다.

플레이어가 실제 물을 밟고 걸으면 좌우 발 위치에서 파문과 물방울이 생긴다. 달리기와 착지는 더 큰 효과를 내고, 공중·마른 땅·적설 위에서는 생성하지 않는다. 파문은 웅덩이 바깥으로 나가는 부분을 숨기며 짧은 수명 뒤 제거한다. 발 높이가 흙길 아래에 묻히지 않도록 렌더링된 길에도 충돌 표면을 맞췄다.

반사 기준 높이는 고정하며 플레이어를 따라 움직이지 않는다. 정사영 카메라의 반사 영상에 수신 지면의 실제 world position을 투영한다. 이전의 y 높이 평탄화는 높이 차이를 절반만 보정해 먼 울타리 반사가 떨어져 보이게 했다. 촬영 영역은 전체 지형 높이 범위만큼 세로로 확장하고 텍스처 높이도 함께 늘려 작은 꽃의 픽셀 밀도를 유지한다. 물 유입·침식 시뮬레이션은 없으며, 물이 충분할 때만 추가 반사 카메라가 동작한다.

반사 대상은 오브젝트 이름·종류별 허용 목록으로 분류하지 않는다. 캐릭터·꽃·풀·나무·가구·울타리·건물 등 원본 카메라에서 렌더링하는 모든 월드 메쉬가 대상이다. 물 자체(layer 4), 날씨·일시 효과(layer 13)는 중복 반사를 피하려고 제외한다. 물웅덩이 반사에서는 수신 지면·흙길만 촬영 중 잠깐 숨겨 아래쪽 시야를 가리지 않게 하고 반드시 원상 복구한다. 특정 높이의 절단면으로 낮은 꽃을 지우던 처리도 제거했다. 실제 물 밖에 투영되거나 다른 물체에 가려진 반사는 자연스럽게 보이지 않을 수 있다.

반사 좌표는 GPU의 렌더 텍스처 Y 반전을 중복 적용하지 않는 뷰포트 좌표로 통일했다. 기존에는 텍스처의 반대쪽을 읽어 물체가 엉뚱한 곳에 보이고 캐릭터 반사가 사라졌다. 실제 색상 표식 위치와 투영 좌표를 비교하고, 캐릭터를 반사 카메라에서만 숨겼을 때 웅덩이 화면이 달라지는지 검증한다.

태양·달 그림자의 표시 거리는 120m, 4개 캐스케이드, Very High 해상도로 설정한다. 기존 42m는 약 45m 떨어진 추적 카메라에서 지면을 포함하지 못했다. 캐릭터는 그림자 캐스팅·수신과 화면 밖 스킨 갱신을 활성화한다. 픽셀 버퍼를 표시할 때 별도 빈 화면 카메라로 검정 여백을 지워 Game View의 “No cameras rendering” 표시도 방지한다.

시간대 조명은 주변광 + 음수가 아닌 직접광으로 계산한다. 기존에는 밝은 주변광 그림자색에서 어두운 노을·달빛 색으로 보간해 그림자가 오히려 밝아질 수 있었다. 동일 지면 픽셀에서 그림자 ON/OFF를 비교하여 Morning·Noon·Sunset·Night 모두 그림자가 밝기를 증가시키지 않는지 검증한다.

가까운 횃불도 그림자를 만든다. 플레이어가 광원 범위 +2m 안에 있을 때 최대 두 개의 횃불에 512 해상도의 포인트 그림자를 활성화해, 멀리 있는 모든 횃불을 계속 렌더링하지 않는다.

적설량 40%부터 걸음마다 좌우 부츠 앞부분·뒤꿈치 모양을 눈 위에 남긴다. 4초간 유지한 뒤 서서히 흐려지고 생성 후 18초에 제거된다. 눈이 녹으면 기존 자국도 지워진다. 최대 128개를 순환 재사용하며, 공중 이동에는 생성하지 않고 착지에는 두 발 자국을 남긴다.

완전한 Standard/PBR 셰이딩이나 유체 시뮬레이션은 아니다. GGX는 직접광 근사이며 실시간 평면 반사로 수면의 주변 풍경을 보완한다.

## 비교 조작

| 키 | 기능 |
| --- | --- |
| J | Hybrid → Toon → 연속 명암 |
| K | 노멀 맵 켜기/끄기 |
| C | 수면 반사 켜기/끄기 |
| M | 야영지 / 호숫가 이동 |
| Tab | 픽셀 해상도 / 화면 해상도 |
| O | 선화 |
| WASD / Shift / Space | 이동 / 달리기 / 점프 |
| Q,E / 휠 | 카메라 회전 / 확대 |
| F1~F4 / L | 아침·정오·노을·밤 / 시간 흐름 |
| 1,2,3 / B / V | 맑음·비·눈 / 바람 / 물결 |

상세한 잎은 360픽셀 화면에서 작은 점으로 합쳐진다. 확대하거나 Tab으로 원래 해상도와 비교할 수 있다.
원본 나무는 약 160만 삼각형이므로 두 그루만 사용했다. 이 씬은 표현 비교용이며 넓은 숲 전체에 배치할 수준의 LOD·잎 군집 최적화는 아직 하지 않았다.

## 검증과 재생성

- 메뉴: `Pixel Art Lab > Create Semi-Real Woodland Comparison` (비교 씬과 파생 재질을 다시 만든다).
- 렌더링 검증: `PixelArtLab.Editor.DetailedWoodlandVerification.Run`.
- Unity Play 모드 이동·충돌·점프 검증: `PixelArtLab.Editor.DetailedWoodlandVerification.Play`.
- 결과: `Previews/Detailed-Woodland-Verification.txt`, `Previews/Detailed-Woodland-Playtest.txt`.
- 맵 전역 분포 검증: `PixelArtLab.Editor.PuddleWorldVerification.Distribution`.
- 발 상호작용 Play 검증: `PixelArtLab.Editor.PuddleWorldVerification.Play`.
- 반사 좌표·캐릭터 반사·나무/캐릭터/횃불 그림자 검증: `PixelArtLab.Editor.ReflectionShadowVerification.Run`.
- 낮은 꽃·고도별 반사·시간대별 눈 그림자 검증: `PixelArtLab.Editor.TerrainReflectionVerification.Run`.
- 적설 임계값·실제 걷기·자국 소멸·화면 카메라 검증: `PixelArtLab.Editor.SnowFootprintVerification.Play`.
- 실행 파일은 빌드하지 않았다.
