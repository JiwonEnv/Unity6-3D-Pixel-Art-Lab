## 0. Unity 화면에서 쓰는 곳 세 군데

| 이름 | 위치 | 여기서 하는 일 |
|---|---|---|
| **Project 창** | 화면 아래 | 씬 · 에셋 찾기 |

## B. 내 프로젝트에 넣기

### 1. 폴더 복사

`Assets/PixelArtLab`에서 다섯 폴더만 복사합니다. `Samples`는 이 프로젝트 전용이라 빼도 됩니다.

| 폴더 | 내용 |
|---|---|
| `Runtime` | 재사용 코드 (카메라 · 환경 · 물 · 눈 · 대기 …) |
| `Shaders` | `SH_SpriteToon` + 기술 모듈 `Lab*.hlsl` |
| `Editor` | URP 설정 · 키워드 동기화 · 점검 도구 |
| `Settings` | URP 파이프라인 에셋 |
| `Presets` | 기본 프로필 · 스타일 SO |

> **왜 Runtime만 복사해도 되나?** 어셈블리 참조가 안쪽으로만 갑니다 (Samples → Runtime). Runtime은 다른 폴더를 모릅니다.

### 2. URP 설정

1. Package Manager에서 **URP 17.3** 설치
2. 메뉴 `Pixel Art Lab > Set Up PC URP` 실행
3. `Project Settings > Tags and Layers`에서 레이어 **4 Water · 8 Character · 13 Effects**를 비워 두거나, 번호가 다르면 `Runtime/Core/LabLayers.cs`의 숫자를 바꿉니다.

### 3. 씬에 붙이기

| 붙일 곳 | 컴포넌트 | 필수 |
|---|---|:---:|
| 빈 오브젝트 `Environment` | `EnvironmentState` (프로필은 `Presets/SO_TimeOfDay_Default` · `SO_Weather_Default`) | ✅ |
| 같은 오브젝트 | `SunMoonDriver` · `SkyFogDriver` · `PracticalLightManager` · `SurfaceStyleSet` | 필요한 것만 |
| 카메라 | `ExplorationCamera` (픽셀 버퍼) · `PixelLinework` (선화) · `PixelVolumetrics` (빛줄기) · `PlayerVisibility` (가림 해소) | 필요한 것만 |
| 캐릭터 | `MotionCharacter` (기존 컨트롤러 그대로 둠) · `SteppedAnimator` | 발자국 · 카메라 추적에 필요 |
| 물 | `WaterBody` → 컴포넌트 메뉴 `Fit To Renderer` | 물 쓸 때 |
| 등불 Light | `PracticalLight` | 등불 쓸 때 |

### 4. 머티리얼

1. 셰이더를 **PixelArtLab/Sprite Toon**으로 바꿉니다.
2. 기능은 Inspector에서 켭니다: `Alpha cutout` (잎) · `Puddles` (지면) · `Water surface` (물) · `Semi-real shading blend` (실사 텍스처).
3. 머티리얼을 다른 프로젝트에서 가져왔다면 `Pixel Art Lab > Materials > Sync Sprite Toon Keywords`.

> **왜 Sync?** 기능 코드는 키워드로 켜고 끕니다. Inspector에서 바꾸면 자동이지만, 가져온 머티리얼은 값과 키워드가 어긋날 수 있습니다.

### 5. 확인

`Pixel Art Lab > Tools > Check Missing Scripts` → `Previews/Project-Health.txt`에 누락 스크립트 0이면 끝.

## 내 셰이더에서 기술 하나만 쓰기

모듈을 include하고 함수 하나를 부르면 됩니다. 값은 `EnvironmentState`와 `SurfaceStyleSet`이 보냅니다.

```hlsl
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
#include "Assets/PixelArtLab/Shaders/LabSnow.hlsl"

half3 albedo = baseColor.rgb;
albedo = LabSnowAlbedo(albedo, normalWS, 0);   // 위를 향한 면에 눈
```

| 모듈 | 대표 함수 |
|---|---|
| `LabSnow` | `LabSnowAlbedo` |
| `LabWetness` | `LabWetAlbedo` · `LabWetSheen` |
| `LabPuddles` | `LabApplyPuddles` · `LabPuddleReflect` |
| `LabWater` | `LabWaterNormal` · `LabWaterGlint` · `LabWaterReflection` |
| `LabHeightFog` | `LabApplyHeightFog` |
| `LabToonLighting` | `LabSunLight` · `LabLocalLight` · `LabLegacyAttenuation` |
| `LabWind` | `LabDeformVertex` (모든 패스의 정점 셰이더에서) |
