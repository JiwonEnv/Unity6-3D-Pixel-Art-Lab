# 🩹 6. 문제 해결

## 화면이 이렇게 보이면

| 증상 | 원인 | 해결 |
|---|---|---|
| 카메라가 움직이면 **픽셀이 자글자글** | 카메라가 텍셀 사이에 있음 | 카메라에 `ExplorationCamera`, `pixelated` 켜기 |
| 캐릭터만 **자글자글** | 모델이 텍셀 격자에 안 맞음 | 캐릭터에 `PixelCharacterAlignment`, 법선 정리 (`AuthoredNormalProfile`) |
| 화면이 **분홍색** | 셰이더 컴파일 실패 또는 URP가 아님 | `Pixel Art Lab > Set Up PC URP` 실행, Console에서 셰이더 에러 확인 |
| 명암이 **온통 검정** | 스타일 값이 0 (셰이더 전역값이 비어 있음) | 씬에 `EnvironmentState` 또는 `SurfaceStyleSet`이 있는지 확인 (없어도 로드 시 기본값이 들어가야 정상) |
| 웅덩이 · 물 · 잎이 **안 보임** | 머티리얼 키워드와 값이 어긋남 | `Pixel Art Lab > Materials > Sync Sprite Toon Keywords` |
| **웅덩이가 하나도 없음** | 젖음이 0이거나, 지면이 `minimumHeight`(.38m)보다 낮음 | 날씨 비(2키), 평지면 `PuddleStyle.minimumHeight` 낮추기 |
| 웅덩이에 **반사가 없음** | 젖음 .22 미만이면 반사를 건너뜀 | 비가 충분히 내린 뒤 확인 |
| **눈 발자국이 안 찍힘** | 적설 40% 미만, 또는 `terrainOnly`인데 지면에 웅덩이 머티리얼이 아님 | 눈(3키) 후 기다리기, `terrainOnly` 끄기 |
| 물에 **거품이 엉뚱한 곳** | `WaterBody` 타원이 물과 다름 | 컴포넌트 메뉴 `Fit To Renderer` |
| 비가 **호수 바닥에 떨어짐** | 물에 `WaterBody`가 없음 | 물 오브젝트에 `WaterBody` |
| **높이 안개가 하얗게 떠 보임** | 색을 선형 변환 없이 보냄 | (해결됨) 직접 수정했다면 `Color.linear`로 보내기 |
| **블룸이 안 보임** | 렌더러 후처리 데이터 없음 · LDR · Volume 저장 안 됨 | `Set Up PC URP` 다시 실행, HDR 켜기 |
| 빛줄기에 **망사 무늬 · 바둑판 잡음** | 디더 · 지터 | (해결됨) `bandStep`을 0으로 두면 부드러운 빛줄기 |
| **노을에 빛줄기가 없음** | 해 세기에 Daylight를 곱함 | (해결됨) 달 감쇠는 밤에만 |
| Volume 안개가 **반영 안 됨** | 값 체크박스를 안 켬 | Volume 칸 왼쪽 체크 |
| 플레이 시작 직후 **검은 화면** | 파이프라인 재생성 때 볼륨 스택 해제 | (해결됨) 최신 코드 사용 |
| 등불이 **모두 같은 박자로 일렁임** | 시드가 로컬 위치 | (해결됨) 월드 위치 시드 |
| **나무 투명화 · 벽 뒤 실루엣이 없음** | 카메라에 `PlayerVisibility`가 없거나 가림막에 `PlayerOccluder`가 없음 | 둘 다 추가하고 종류(자연 / 건물) 지정 |

## 값을 바꿨는데 그대로일 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 컴포넌트 기본값을 바꿨는데 씬은 그대로 | 씬에 저장된 값이 우선 | Inspector에서 직접 바꾸거나 컴포넌트 메뉴 Reset |
| 스타일 SO를 고쳤는데 그대로 | 그 SO가 `SurfaceStyleSet`에 끼워져 있지 않음 | Environment 오브젝트의 `SurfaceStyleSet` 칸 확인 |
| 코드로 머티리얼 값을 바꿨는데 그대로 | 키워드가 안 켜짐 | 바꾼 뒤 `SpriteToonKeywords.Sync(material)` |

## 점검 도구

| 메뉴 | 하는 일 |
|---|---|
| `Pixel Art Lab > Tools > Check Missing Scripts` | 모든 씬의 누락 스크립트 → `Previews/Project-Health.txt` |
| `Pixel Art Lab > Materials > Sync Sprite Toon Keywords` | 모든 Sprite Toon 머티리얼 키워드 재동기화 |
| `Pixel Art Lab > Techniques > Build Test Scenes` | 기술 테스트 씬 11개 다시 만들기 |

## 값이 망가졌을 때

스타일 · 프로필 SO를 `Presets/SO_*_Default`로 바꿔 끼우면 처음 값으로 돌아갑니다.
어떤 기술이 원인인지 모르겠으면 **테스트 씬에서 그 기술 하나만** 켜 보며 찾습니다.
