# 배경 조명 설계 (PC)

목표: **Replaced처럼 디테일이 살아 있고 빛과 공기가 느껴지는 배경**에
**Never's End처럼 또렷한 도트 캐릭터**를 얹는다. 대상 플랫폼은 PC다.
대상 씬은 `Semi-Real-Pixel-Woodland`이며, 다른 씬은 작업 기록으로 유지한다.

## 1. 렌더 파이프라인 결정: URP 유지

자세한 근거와 다시 검토할 조건은 [렌더 파이프라인 결정](Render-Pipeline-Decision.md)에 정리했다.

HDRP는 볼류메트릭 안개, 물리 기반 노출, HDR 블룸을 기본으로 제공한다.
하지만 이 프로젝트 그래픽의 뼈대는 **직접 계산하는 툰 조명**이다.
광원마다 명암 단계, 그림자 색, 횃불 감쇠를 직접 계산한다(Never's End 발표의 "빛마다 툰 램프").

| 항목 | URP (PC 설정) | HDRP |
| --- | --- | --- |
| Sprite Toon 툰 조명 | 그대로 사용. 광원 루프를 셰이더에서 직접 돈다 | HDRP 광원 루프에 직접 연결해야 함. Shader Graph는 커스텀 조명 모델을 지원하지 않음 |
| 물체 ID 선화, 가림 해소 | RenderGraph 렌더러 기능 그대로 | Custom Pass로 다시 작성 |
| 저해상도 픽셀 버퍼 | 그대로 | 가능하지만 노출·TAA·볼류메트릭 버퍼를 픽셀 해상도에 맞춰 다시 조정 |
| 볼류메트릭 빛줄기 | 직접 구현 (아래 L5) | 기본 제공 |
| HDR, 블룸, 그레이딩 | 기본 제공 | 기본 제공 |
| 광원 개수 | Forward+로 물체당 한도 해제 | 제한 없음 |

HDRP로 얻는 것은 볼류메트릭 하나다. 반면 잃는 것은 툰 조명 제어 전체와 지금까지 만든 렌더 기능 이식이다.
**URP를 PC 사양으로 재설정**하고, 볼류메트릭만 직접 구현한다.
저해상도 버퍼(약 640×360)에서 레이마칭하므로 PC에서는 비용이 작다.

## 2. 레퍼런스에서 뽑은 조명 특징

Replaced 캡처(바 실내, 창고) 기준:

1. **어두운 주변광, 강한 국소 광원.** 화면 대부분은 어둡고, 벽등·스포트라이트 주변만 밝다. 명암비가 크다.
2. **생활 조명이 많다.** 벽등, 램프, 천장등이 각각 작은 빛 웅덩이를 만든다.
3. **공기 중 빛줄기.** 천장 조명이 안개 속에 원뿔형 빛줄기를 드리운다.
4. **광원 자체의 번짐.** 전구와 램프 주변에 부드러운 빛무리가 있다.
5. **색온도 대비.** 따뜻한 생활 조명과 차가운 청록색 그늘이 섞인다.
6. **화면 가장자리가 어둡다.** 비네트와 원근 안개가 시선을 중앙으로 모은다.
7. **배경 디테일은 유지한다.** 텍스처 디테일은 많지만, 조명이 덩어리를 묶어서 어수선하지 않다.

## 3. 현재 상태와의 차이

| 특징 | 현재 | 원인 |
| --- | --- | --- |
| 명암비 | 밤에도 주변광이 그림자 색의 24% 수준으로 남아 전체가 평평함 | `SunLighting`의 주변광 하한 `lerp(.24,1,daylight)` |
| 생활 조명 | 태양 1개, 횃불 4개(범위 5.5m)뿐 | 배치 부족. 지면이 150m짜리 메시 하나라 Forward 방식의 물체당 한도 4개가 맵 전체에 걸림 |
| 빛줄기 | 없음 | URP에 볼류메트릭 없음 |
| 빛 번짐 | 거의 없음 | LDR 버퍼. 발광 재질이 불꽃 하나(0.6)뿐 |
| 원근 안개 | 보이지 않음 | 안개 시작 80m > 보이는 지면 30~60m. 정사영 카메라라 거리 안개는 화면 전체에 균일하게 덮임 |
| 색온도 | 시간대 색은 있으나 따뜻함/차가움 대비가 약함 | 주변광 색과 횃불 색만 사용 |

## 4. 조명 레이어 설계

### L1. HDR과 노출
- URP 에셋: HDR 켜기(픽셀 버퍼라 대역폭 부담 작음), 노출은 고정한다. 톤매핑은 쓰지 않는다(None). 1을 넘는 값은 예전처럼 잘려서 툰 팔레트 색이 그대로 유지된다.
- 발광 재질(불꽃, 랜턴 유리, 창문)은 HDR 값 2~6을 쓴다. 빛 번짐은 이 값으로만 생긴다.

### L2. 조명 비율과 시간대 팔레트
- 기준 밝기 비율 (주광 : 보조광 : 주변광)

  | 시간대 | 비율 | 의도 |
  | --- | --- | --- |
  | 낮 | 1 : 0.35 : 0.25 | 현재와 비슷 |
  | 노을 | 1 : 0.25 : 0.12 | 긴 그림자, 주황/보라 대비 |
  | 밤 | 달 0.25 : 생활 조명 1 : 주변광 0.06 | 생활 조명이 화면을 이끈다 |

- `WorldEnvironment`의 시간대 곡선을 이 비율로 다시 맞춘다. 툰 단계(4단계)는 유지하고, 밤 주변광 하한만 낮춘다.
- 그늘색은 청록 쪽, 생활 조명은 2700~3200K 주황 쪽으로 대비를 준다.

### L3. 생활 조명
- 렌더링 방식을 **Forward+**로 바꿔 물체당 광원 한도를 없앤다. Sprite Toon은 이미 `_CLUSTER_LIGHT_LOOP`를 지원한다.
- 야영지와 호숫가에 랜턴, 기둥등, 텐트 안 등불을 배치한다. 광원마다 툰 감쇠(기존 횃불 곡선)를 쓴다.
- 그림자는 가까운 생활 조명 4개만 켠다. 기존 "가까운 횃불 2개" 규칙을 4개로 넓힌다.
- 목표: 화면에 보이는 광원 최대 16~24개.

### L4. 높이 안개
- 거리 안개 대신 **월드 높이 안개**를 쓴다. 낮은 지대, 호수, 숲 바닥에 안개가 고인다. 정사영 카메라에서도 깊이감이 생긴다.
- Sprite Toon에서 `world.y` 기반 지수 감쇠와 저주파 노이즈를 쓴다. 색은 시간대 팔레트를 따른다.
- 생활 조명이 안개를 물들이도록 근처 광원 색을 더한다(L5와 공유).

### L5. 볼류메트릭 빛줄기
- 렌더러 기능에 **픽셀 해상도 레이마칭 패스**를 추가한다.
  - 대상 광원: 태양/달 그림자맵과, 볼류메트릭 표시를 켠 스포트·포인트 광원
  - 샘플 수: 픽셀당 16~24스텝, 4×4 디더로 지터를 주고 같은 해상도에서 1회 블러
  - 결과를 툰처럼 3~4단계로 양자화해 도트 느낌의 빛 계단을 만든다(Replaced의 부드러운 빛줄기와 Never's End의 단계 사이)
- 숲 사이 햇살, 텐트 입구, 랜턴 원뿔처럼 "보여야 할 곳"에만 켠다.

### L6. 빛 번짐
- URP Bloom을 픽셀 버퍼에서 적용한다. 임계값 1.0, HDR 발광 재질만 반응한다.
- 결과는 업스케일 전에 만들어지므로 번짐도 픽셀 단위로 보인다.

### L7. 그레이딩과 비네트
- 시간대별 Volume 프로필을 둔다(화이트밸런스, 스플릿 토닝, 비네트 0.2~0.3).
- `WorldEnvironment`가 시간대에 따라 프로필 가중치를 섞는다.

### L8. 캐릭터 가독성
- 어두운 배경에서도 캐릭터 실루엣 외곽선, 림 라이트 밴드, 계단식 애니메이션은 유지한다.
- 캐릭터에는 그레이딩과 안개를 약하게 적용해 배경과 분리한다.

## 5. 1단계 결과 (2026-11-02)

- URP 에셋을 PC용으로 바꿨다(`PixelArtLab-PC-URP`): HDR, Forward+, 주광 그림자 4096, 보조 광원 그림자 아틀라스 4096. 모바일 이름이던 에셋은 GUID를 유지한 채 이름만 바꿨다.
- `WorldEnvironment`에 조명 비율 값을 추가했다: 밤 주변광 `nightAmbient` 0.1(기존 셰이더 고정값 0.24), 달빛 `moonIntensity` 0.3(기존 0.52), 밤 그늘색 청록 `nightAmbientTint`. 주변광은 `sqrt(Daylight)`로 올라가 노을에도 읽힌다.
- 불꽃 발광을 HDR 4로 올리고, Woodland에 Bloom(임계값 0.95, 강도 1)·비네트(0.22)·톤매핑 None을 적용했다(`Pixel Art Lab > Background Lighting > Apply Phase 1`).
- 플레이 모드 캡처: `Pixel Art Lab > Background Lighting > Capture Play Mode` → `Previews/Lighting`. 후처리는 플레이 모드 렌더에서만 적용되므로 화면 밖 렌더 검증과 구분한다.

| 시간대 | 평균 밝기 | 명암비 p95/p10 (이전 → 이후) |
| --- | --- | --- |
| 정오 | 0.31 | 1.6 → 1.7 |
| 노을 | 0.11 | 3.0 |
| 밤 | 0.11 | 2.1 → 3.1 |

- 남은 과제: 노을은 읽히지만 주황·보라 대비가 약하다. 5단계 그레이딩에서 다룬다.

## 6. 2단계 결과 (2026-11-02)

- 야영지 5개, 호숫가 3개, 총 8개의 랜턴을 단순한 형태(나무 기둥, 철제 덮개, 발광 유리)로 배치했다. 기존 횃불 4개와 합쳐 생활 조명은 12개다(`Pixel Art Lab > Background Lighting > Apply Phase 2`).
  - 야영지: 남쪽·동쪽 길 입구, 큰 텐트·작은 텐트 앞, 상자 위 촛불 랜턴
  - 호숫가: 길 랜턴 2개(따뜻한 색), 카누 옆 낚시등 1개(차가운 색, 색온도 대비)
- `PracticalLight`: 랜턴마다 낮·밤 밝기를 갖고, 유리 발광이 빛 세기에 맞춰 함께 켜진다. 랜턴은 낮에는 꺼지고 해 질 녘부터 켜진다. 유리 발광은 HDR 2.2다(2.5를 넘으면 흰색으로 잘려 색이 사라짐).
- 그림자 규칙: 기존 "배열 순서상 앞 2개"를 **플레이어와 가까운 순 4개**(`WorldEnvironment.shadowedPracticals`)로 바꿨다.

| 장면 | 명암비 p95/p10 (1단계 → 2단계) |
| --- | --- |
| 밤 야영지 | 3.1 → 3.5 |
| 노을 야영지 | 3.0 → 3.2 |
| 밤 호숫가 | 4.3 (신규 캡처) |

- 프레임 시간(에디터 플레이 모드, 밤 야영지, 상한 해제): 랜턴 끔 2.02ms, 켬 1.98ms(중앙값). 측정 오차 범위 안이라 차이가 없다. GPU 시간만 따로 잰 값은 아니다.

## 7. 3단계 결과 (2026-11-02)

- `Sprite Toon` 전방 패스에 **높이 안개**를 넣었다. 월드 높이 기준 지수 감쇠와 느린 저주파 흔들림을 쓴다. 호수(높이 약 0.3m)와 낮은 물가에 짙고, 야영지(약 1.2m)는 옅고, 언덕은 거의 맑다.
- 생활 조명이 안개를 물들인다. 광원 루프에서 감쇠량만큼 빛을 더하고 그림자는 무시해, 랜턴 주변 공기가 은은하게 빛난다.
- 캐릭터는 안개를 35%만 받아 배경과 분리된다(L8).
- `WorldEnvironment` 값: `nightFogDensity` 0.28, `dayFogDensity` 0.12, `fogBaseHeight` 0.3m, `fogFalloff` 1.2m, `fogDrift` 0.6, `lampFogGlow` 0.08. 색은 밤 청록, 노을 보라, 낮 회청이고, 비·눈이 오면 짙어진다. `heightFog`로 끄고 켤 수 있다.
- 처음 캡처에서는 화면이 회색 막처럼 덮였다. 원인은 `SetGlobalVector`가 sRGB→선형 변환을 하지 않아 어두운 청록(0.15)이 밝은 회색으로 들어간 것이었다. `Color.linear`로 변환해 고쳤다.

| 장면 | 명암비 p95/p10 (안개 없음 → 있음) | 판단 |
| --- | --- | --- |
| 밤 야영지 | 3.5 → 3.1 | 옅은 공기감, 불빛 대비 유지 |
| 밤 호숫가 | 4.3 → 2.7 | 호수 위 안개, 낚시등 주변이 빛남 |
| 노을 호숫가 | 3.6 → 1.6 | 보라 안개가 호수를 덮지만 수면과 카누는 보임. 가장 강한 장면 |

- 캡처 도구는 장면마다 "전체 / 후처리 없음 / 안개 없음" 세 가지를 저장한다.

## 8. 단계별 계획

| 단계 | 내용 | 확인 방법 |
| --- | --- | --- |
| 1 | PC용 URP 재설정(HDR, Forward+, 소프트 그림자, 그림자 해상도), L2 조명 비율, L6 블룸 | 낮·노을·밤 캡처 비교, 기존 검증 전체 통과 |
| 2 | L3 생활 조명 배치(야영지·호숫가), 그림자 규칙 확장 | 밤 캡처, 광원 수·프레임 시간 측정 |
| 3 | L4 높이 안개 | 지대별 안개 농도 캡처 |
| 4 | L5 볼류메트릭 빛줄기 | 숲 햇살·랜턴 원뿔 캡처, 패스 비용 측정 |
| 5 | L7 그레이딩, 시간대 혼합 | 시간대 전환 연속 캡처 |

모든 단계에서 기존 자동 검증(렌더링, 반사·그림자, 가림 해소, 플레이)을 통과해야 한다.
**실행 파일은 빌드하지 않는다.**

## 9. 성능 목표 (PC)

- 기준: GTX 1060급, 1080p 출력(내부 버퍼 약 640×360), 60fps
- 볼류메트릭 패스: 1ms 이하
- 생활 조명 그림자: 포인트 광원 4개 × 512 큐브맵
- 상세 나무(그루당 160만 삼각형)는 별도 LOD 작업 대상으로 남긴다
